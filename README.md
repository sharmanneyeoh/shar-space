# 🌸 Shar's Space

**A pink, all-in-one personal planner that lives on my iPhone home screen.**

Shar's Space brings together the things I use day to day: a calendar, a to-do board, a journal, a money tracker and habit trackers, all in one place. It's designed to feel soft, calm and personal, and I can customise almost everything in it.

---

## ✨ What's inside

### 🏠 Home: my day at a glance
- A greeting with my name and a new **affirmation** every day
- Quick stats: **tasks to do**, **plans today** and **money spent this month**
- **Little habits**: trackers I make myself, like water 💧, skincare 🧴, reading 📖 or vitamins 💊
  - *Check-off* habits: tap once when done
  - *Counter* habits: tap +1 toward a daily goal (e.g. 8 glasses of water)
  - Each habit has a progress ring, the last 7 days and my current **streak**
- **Today** list: today's plans, tasks due today and anything overdue
- **Mood check-in**: tap an emoji to start today's journal entry

### 📅 Calendar
- Month view: swipe left or right, or use the arrows, to change month
- Add **plans** with a time, end time, colour and notes
- Plans can **repeat** every day, week, month or year (perfect for birthdays 🎂)
- Little dots show plans and tasks due, and a ♡ marks days I journaled
- Tap any day to see everything for that day: plans, tasks, journal entries and money spent

### ✅ Tasks: kanban board
- Columns like **To Do ♡ → In Progress ✿ → Done ✓**
- **Tap a column title to rename it**, and add as many columns as I like
- Give each column a colour and move columns left or right
- **Hold a task and drag it** to another column or a new position
- Each task can have notes, a **due date** (overdue ones turn red) and a colour label
- The last column counts as "done", so finished tasks no longer show as due

### 📖 Journal
- Write entries with a date, an optional title and a **mood** 🥰😊😌😐😔😢😤
- A different writing prompt each time, like *"What made you smile today?"*
- **Search** through all my entries
- See **my moods this month** at a glance
- Entries are grouped by month, like a little diary

### 💸 Money
- Log **expenses** and **income** with a category, date and note
- See how much I've **spent this month**, plus income and balance
- Set a **monthly budget** with a progress bar showing how much is left
- **"Where it went"**: spending by category with bars and percentages
- Browse past months with the arrows
- Categories are my own, with emojis, e.g. Food 🍓, Beauty 💄, Shopping 🛍️

### ⚙️ Settings: make it mine
- My **name** for the greeting
- **5 pink themes**: Blush, Strawberry Milk, Lavender Rose, Peachy Pink and Midnight Pink (dark mode)
- **Currency**: RM, $, S$, £, €, ₱, ¥, ₩, ₹, or type my own
- Choose whether the week starts on **Sunday or Monday**
- Add or remove **money categories**
- **Backup and restore** all my data as a file

---

## 🔒 Privacy

All my data is saved **only on my own phone**. There's no account, no sign-in, and nothing is sent to a server.
That also means: **use Settings → Save backup now and then** and keep the file in iCloud or Files, just in case.

---


## 🛠️ Built with

Plain **HTML, CSS and JavaScript**, with no frameworks and no build step.

| File | What it does |
|---|---|
| `index.html` | The page that loads the app |
| `styles.css` | All the pink styling and the 5 themes |
| `app.js` | Every feature: calendar, kanban, journal, money, habits, settings |
| `manifest.json` | Lets the phone install it as an app (name, icon, colours) |
| `sw.js` | Service worker that makes the app work offline |
| `icons/` | The heart app icons |
